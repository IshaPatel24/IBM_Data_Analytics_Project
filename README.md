# IBM Retail Analytics Project

## Project Overview

This project performs end-to-end retail sales analytics using the Online Retail Dataset.

The project includes:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Revenue Analysis
- Product Analysis
- Country-wise Sales Analysis
- Monthly Revenue Trend
- RFM Customer Segmentation
- K-Means Clustering
